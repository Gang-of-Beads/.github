# Security policy

This is the default policy for every Gang of Beads repository that has no `SECURITY.md` of its own. A repository's own file, where there is one, takes precedence; PI WEB's describes its threat model in detail.

## Reporting a vulnerability

Report it privately: open the affected repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue, discussion or pull request for a vulnerability.

Include what you found, the version or commit, how to reproduce it, and what an attacker gains. You will get an acknowledgement within a few days; the fix, its release and the advisory are coordinated with you.

## Supported versions

Only the latest release of each package receives security fixes.
