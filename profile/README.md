## Gang of Beads

Open-source tools around the [pi coding agent](https://github.com/earendil-works/pi/tree/main/packages/coding-agent).

- **[PI WEB](https://github.com/Gang-of-Beads/pi-web)**: a web UI for persistent pi sessions on one or many machines, from a desktop or a phone.
- **PI WEB plugins**: [Goals](https://github.com/Gang-of-Beads/pi-web-goals), [Subagents](https://github.com/Gang-of-Beads/pi-web-subagents), [Background runs](https://github.com/Gang-of-Beads/pi-web-background-runs), [Workflows](https://github.com/Gang-of-Beads/pi-web-workflows) and [Themes](https://github.com/Gang-of-Beads/pi-web-themes).

Contributions are welcome: each repository's README and CONTRIBUTING say how. Please follow the [Code of Conduct](https://github.com/Gang-of-Beads/.github/blob/main/CODE_OF_CONDUCT.md) and report vulnerabilities privately as the [security policy](https://github.com/Gang-of-Beads/.github/blob/main/SECURITY.md) describes.
